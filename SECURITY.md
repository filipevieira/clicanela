# Política de Segurança (Security Policy)

## Versões Suportadas

Como o **Clicanela** é um projeto de código aberto e focado em diversão, nós oferecemos suporte e atualizações de segurança apenas para a versão mais recente do código disponível na branch `main`.

| Versão | Suportado          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Antigas | :x:                |

## Relatando uma Vulnerabilidade

Nós levamos a segurança do Clicanela a sério! Se você é um desenvolvedor ou pesquisador de segurança e encontrou alguma falha (por exemplo, na integração com a CounterAPI ou no código frontend), pedimos que **NÃO** abra uma Issue pública.

Ao invés disso, por favor, reporte de forma privada:
1. Utilize o botão **"Report a vulnerability"** na aba Security do GitHub (caso ativado).
2. Ou envie um e-mail diretamente para: **clicanela@fvds.dev**.

Nós tentaremos responder o mais rápido possível (geralmente em até 48 horas) para investigar e corrigir a vulnerabilidade de forma segura antes de torná-la pública.
