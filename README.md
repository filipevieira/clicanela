# Clicanela 🍂

Descubra o mundo mágico da canela. Clique nela! O Clicanela nasceu de uma piada interna durante uma call de desenvolvimento, e evoluiu para uma aplicação web divertida, responsiva e surpreendentemente "premium".

## 🌟 Funcionalidades

- **Explosão de Canelas:** Uma chuva de emojis interativa sempre que você clica!
- **Placar Global & Local:** Quantas vezes o mundo já clicou na canela? Graças à CounterAPI, os cliques de qualquer pessoa no mundo são somados de forma anônima e em tempo real.
- **Curiosidades Aleatórias:** Descubra histórias, o mito do pássaro guardião, os usos na culinária internacional e até o perigoso "Desafio da Canela".
- **Modo Escuro / Claro:** Um design sofisticado usando Glassmorphism que se adapta à preferência do seu sistema.
- **Acessibilidade & Responsividade:** Interface acessível por teclado, adaptável do celular ao desktop, e com pop-up de conformidade (LGPD) super claro.

## 🛠️ Tecnologias Utilizadas

- **[Vite](https://vitejs.dev/):** Ferramenta de build e servidor de desenvolvimento ultra-rápido.
- **Vanilla JS:** Interação pura no lado do cliente sem frameworks pesados.
- **HTML5 & CSS3:** Design minimalista, animações Keyframes suaves e variáveis CSS.
- **[CounterAPI](https://counterapi.dev/):** API pública REST gratuita para armazenar o nosso contador mundial sem precisar criar e hospedar um banco de dados próprio.

## 🚀 Como rodar localmente

1. Clone o repositório: 
   ```bash
   git clone https://github.com/filipevieira/clicanela.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Rode o servidor de desenvolvimento Vite:
   ```bash
   npm run dev
   ```
4. Abra seu navegador no endereço: `http://localhost:5173`.
