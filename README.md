## 📖 Sobre o Projeto

O **Clicanela** é um projeto irreverente, moderno e muito interativo que nasceu de forma totalmente inesperada: **surgiu de uma piada durante uma call com o time de desenvolvimento**. A brincadeira foi longe demais e se transformou na experiência definitiva sobre... canela!

Cada vez que você acessa o site (ou clica na canela central), você é presenteado com uma nova curiosidade aleatória — seja sobre a especiaria que vale ouro, a charmosa cidade na Serra Gaúcha, a magia mística de atrair prosperidade ou até o povo indígena brasileiro!

Tudo isso acompanhado de um **Contador de Clicanela** pessoal (salvo no seu navegador) para você ver o quão viciado você é em clicar em canelas.

## ✨ Funcionalidades

- 🎲 **Fatos Aleatórios:** Um banco de curiosidades dinâmico que alterna perfeitamente a cada clique.
- 🌓 **Cinnamon Theme:** Suporte nativo a *Dark Mode* e *Light Mode* (alternável pelo usuário) com uma paleta de cores inspirada em tons de canela (marrons terrosos, laranjas vibrantes e beges suaves).
- 🍪 **LGPD Ready:** Um simpático banner de cookies no estilo *glassmorphism*, garantindo que o armazenamento do seu contador e tema seja feito com o seu consentimento.
- ⚡ **Performance Bruta:** Construído puramente com **Vanilla JavaScript** utilizando o **Vite**. Animações suaves, transições de estado e zero frameworks pesados.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Variáveis CSS, Glassmorphism, Keyframes Animations)
- **JavaScript Vanilla** (ES6 Modules, manipulação do DOM e `localStorage`)
- **Vite** (Build Tool super rápida e otimizada)

## 🚀 Como rodar localmente

Se você quiser explorar a magia da canela no seu próprio ambiente local:

1. Clone o repositório:
   ```bash
   git clone https://github.com/filipevieira/clicanela.git
   ```
2. Entre na pasta:
   ```bash
   cd clicanela
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Rode o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

Acesse em `http://localhost:5173`.

## 📦 Deploy

O site foi pensado e otimizado para rodar diretamente via **GitHub Pages**. Toda a aplicação roda no lado do cliente (Front-end estático), necessitando apenas do comando `npm run build` para gerar a pasta `dist` pronta para a nuvem.
